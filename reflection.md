# Reflection

## What changed between my first idea and the final solution?
My first idea was a landing page plus paid ads. I dropped it because a landing page alone doesn't bring students in, and ₹2,000 goes very little way on ads. I moved to a community-first plan built on ambassadors, clubs, and a referral loop, and built a tracker so I can see which channel works each day and shift effort quickly.

## If I had another 24 hours, what would I improve?
- Connect the registration form to Google Sheets or a database so sign-ups are live.
- Add visit and click tracking so I can report a true conversion rate.
- Auto-generate WhatsApp messages and referral links per college and club.
- Build a workshop-day tool to evaluate participants' projects.

## What did AI suggest that I rejected, and why?
- **Connecting an AI model to generate campaign suggestions.** I rejected it because it adds cost and API-key complexity, and would imply more intelligence than the prototype has. Rule-based logic is more honest and does the job.
- **Showing a conversion rate per referral code.** I rejected it because I don't track clicks, so the number would be misleading. I show registrations and share instead.
- **A long, emoji-heavy WhatsApp message.** I rejected it because students skim group chats. A short message with one clear hook is more likely to be read and forwarded.
